# Календарь 2×2

Лёгкое PWA-приложение для графика «2 рабочих / 2 выходных». Работает без сервера и сторонних зависимостей: достаточно открыть `index.html` через локальный веб-сервер или разместить папку на статическом хостинге.

## Что умеет

- показывает календарь по месяцам;
- считает рабочие и выходные дни за выбранный месяц;
- позволяет выбрать стартовую дату и тип стартового дня;
- сохраняет настройки в `localStorage`;
- работает офлайн после первого открытия через service worker;
- корректно считает график через часовые пояса и переходы на летнее/зимнее время.

## Запуск локально

```bash
npm start
```

Затем откройте `http://localhost:8080`.

Можно запустить и без npm:

```bash
python3 -m http.server 8080
```

## Проверка

```bash
npm run lint
npm test
```

Тесты используют встроенный `node:test`, внешние пакеты не нужны.

## Структура

```text
.
├── app.js                 # логика интерфейса и сохранения настроек
├── index.html             # разметка приложения
├── styles.css             # стили и адаптивность
├── sw.js                  # офлайн-кэш PWA
├── manifest.webmanifest   # manifest для установки на устройство
├── utils/calendar.js      # чистые функции расчёта календаря
└── tests/calendar.test.mjs
```

## Идеи для следующего развития

- экспорт смен в `.ics` для Google/Apple Calendar;
- настройка произвольного цикла, например 1/3, 3/3, 4/2;
- отметки отпуска, больничных и праздничных дней;
- расчёт зарплаты по ставке и количеству смен;
- выбор темы оформления и акцентного цвета;
- виджет ближайшей смены на главном экране.
